# Python Practice Assignment 01

## Project Description

This repository contains two beginner-level Python practice projects.
These projects are designed to practice basic Python programming concepts,
user input, data types, arithmetic operations, conditional statements,
and formatted output using f-strings.

## Projects

### 1. Personal Information & Simple Calculator

**File Name:** `personal_calculator.py`

#### Features
- Takes user's name as input.
- Takes user's age as input.
- Takes two numbers from the user.
- Calculates:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Displays all information using f-strings.

#### Example Output

```text
Enter your name: Rahim
Enter your age: 22
Enter first number: 20
Enter second number: 10

Hello, Rahim!
Your age is 22.
Addition: 30
Subtraction: 10
Multiplication: 200
Division: 2.0
```

### 2. Student Grade Calculator

**File Name:** `grade_calculator.py`

#### Features
- Takes student's name as input.
- Takes marks for three subjects:
  - Math
  - English
  - Python
- Calculates average marks.
- Determines the final grade.
- Checks invalid marks (below 0 or above 100).
- Displays the student's name, average marks, and final grade.

#### Grading System

| Average Marks | Grade |
|---------------|-------|
| 80 - 100      | A+    |
| 70 - 79       | A     |
| 60 - 69       | A-    |
| 50 - 59       | B     |
| 40 - 49       | C     |
| Below 40      | F     |

#### Example Output

```text
Enter student name: Rahim
Enter Math marks: 85
Enter English marks: 75
Enter Python marks: 90

Student Name: Rahim
Average Marks: 83.33
Final Grade: A+
```
